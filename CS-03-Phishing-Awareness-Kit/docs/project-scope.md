# CS-03 — Phishing Awareness Kit

## 1. Problem Statement

Phishing and social engineering remain significant attack vectors because attackers exploit human trust, urgency, curiosity, and authority.

Organizations require more than generic security-awareness training. They need a repeatable process for educating users, measuring awareness, and improving reporting behavior.

## 2. Project Objective

Design and demonstrate a controlled phishing-awareness capability using GoPhish and supporting defensive processes.

The project will simulate realistic phishing scenarios within an authorized laboratory environment and evaluate user interaction with the simulation.

## 3. Core Workflow

Threat
↓
Phishing Simulation
↓
User Interaction
↓
Awareness Intervention
↓
Measurement
↓
SOC Response

## 4. Scope

The project includes:

- GoPhish deployment
- Controlled phishing campaign
- Test users
- Email templates
- Awareness landing page
- Campaign metrics
- Phishing recognition guidance
- Phishing reporting procedure
- MITRE ATT&CK mapping
- Defensive recommendations
- Evidence collection

## 5. Out of Scope

- Real-world phishing campaigns
- Unauthorized targeting
- Credential theft
- Collection of real credentials
- Malware delivery
- Targeting users without authorization

## 6. Primary Technology

- GoPhish
- Kali Linux
- Linux
- SMTP test infrastructure
- HTML
- MITRE ATT&CK

## 7. Primary MITRE ATT&CK Technique

T1566 — Phishing

Relevant sub-techniques will be identified based on the final simulation scenario.

## 8. Expected Outcome

The final artifact should demonstrate that a small organization can:

1. Simulate phishing safely.
2. Measure user interaction.
3. Educate users.
4. Encourage phishing reporting.
5. Analyze awareness results.
6. Translate findings into defensive improvements.
