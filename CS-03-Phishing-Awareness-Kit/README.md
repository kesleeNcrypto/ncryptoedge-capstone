# CS-03 — Phishing Awareness Kit

**Status:** Active / Priority

Controlled phishing-awareness capstone project using GoPhish, awareness content, campaign metrics, and defensive analysis.

## Objective

Demonstrate a complete awareness workflow:

**Threat → Simulation → User Interaction → Awareness Intervention → Measurement → SOC Response**

## Planned Components

- GoPhish lab deployment
- Controlled campaign design
- Email templates
- Awareness landing page
- User awareness guide
- Reporting procedure
- Campaign metrics and analysis
- MITRE ATT&CK mapping
- SOC detection/response opportunities
- Evidence and final presentation

## Safety Boundary

Only authorized lab accounts and controlled environments will be used. No real-user credential collection or uncontrolled external targeting.
