# CS-03 — Incident Response

This document maps simulated phishing interactions to the corresponding defensive response workflow.

## Link Clicked — No Credentials

Initial classification:

**P3 — Medium**

Actions:

1. Confirm the interaction.
2. Determine whether content was downloaded or executed.
3. Review endpoint telemetry where available.
4. Analyze the phishing infrastructure.
5. Document evidence.
6. Provide awareness intervention.

## Email Reported — No Interaction

Initial classification:

**P4 — Low**

Actions:

1. Validate the reported message.
2. Extract indicators.
3. Identify other recipients.
4. Recommend blocking or removal where applicable.
5. Record the report as a positive security behavior.

Detailed response procedures will be expanded during implementation.
